# חישוב כבלים, גידי הארקה וזרמי קצר – משרד טיקטין

אפליקציה משרדית (קובץ יחיד `index.html`) לחישוב:
- חתך וכמות כבלים במקביל (עד 16), כולל מקדמי קבוצה
- גיד הארקה PE מנחושת (תקנה 25)
- מפל מתח (עד 3% לפי חוק) וזרם קצר מתפתח בלוח
- לוח ראשי אחרי מונה (שנאי חח״י), שנאי פרטי → לוח ראשי (פסי צבירה EATON / EAE, כבלים וגידים), לוח משני

כבלים רב-גידיים לפי טבלה 90.7, גידים חד-גידיים לפי טבלה 90.8 (תקנות החשמל – העמסה והגנה על מוליכים, התשע״ד-2014).

## פרסום ב-GitHub Pages
1. ליצור מאגר חדש בשם `cable-sc` בחשבון `tiktiny` (ציבורי).
2. להעלות את כל הקבצים, כולל תיקיית `icons` וקובץ `manifest.webmanifest`.
3. Settings → Pages → Branch: `main`, תיקייה `/ (root)` → Save.
4. הכתובת: https://tiktiny.github.io/cable-sc/
